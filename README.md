Proyecto simple creado para experimentar con javacript y API's. 
Nos solicitaron en clase crear una maquina expendedora con una interfaz gráfica en la cual decidiesemos la localización de la máquina expendedora, el producto que queriamos comprar, y un modo para poder reponer los productos.
Quise hacer algo atrevido y diferente y experimenté con JS, Python y API's. Utilicé la IA como mi senior de confianza para que me ayudara a comprender nuevos conceptos, sintasis y funcionalidades. 

¿Que hace?
Se selecciona el producto de la máquina y se le da al botón de aceptar para quitar 1u. de la base de datos.

Puedes cambiar al modo reponer, el cual primero pedirá el número del artículo y después deberás introducir la cantidad deseada. Se modificará el stock en la base de datos.

¿Como lo despliego en local?
Pues solo necesitas correr los scripts en una bbdd SQL (en mi caso utilice SQLDeveloper, lo que utilizabamos en clase), tener instalado python y las dependencias de flask necesarias.
